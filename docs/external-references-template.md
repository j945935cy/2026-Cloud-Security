# 外部正式引用清單模板

這份清單用來協助正式出版前補齊每章外部引用。以下內容以「建議補入的報告、法規、框架與官方文件類型」為主，方便後續逐項查找、驗證與轉換為正式書末參考文獻。

## 使用方式

1. 先依章節補齊官方文件與年度報告。
2. 再補產業調查、案例研究與統計來源。
3. 最後統一格式成正式參考文獻樣式，例如 APA、Chicago 或出版社指定格式。

- AI 治理與數位信任白皮書

## 正式引用格式模板

### 報告類

作者或機構名稱.（年份）.《報告名稱》. 出版單位. URL

### 法規或官方文件類

機關名稱.（年份）.《文件名稱》. 文件編號或版本. URL

### 論文類

作者.（年份）.〈論文名稱〉.《期刊或會議名稱》, 卷期, 頁碼. DOI 或 URL

### 網站或新聞資料類

作者或媒體名稱.（年份, 月日）.〈文章標題〉. 網站名稱. URL
